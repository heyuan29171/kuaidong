谱面编辑教程

用编辑器做一首属于自己的歌，再回到曲库游玩

1. 新建或打开谱面

  • 曲库页点 “导入本地音频做 BGM”，选择 mp3 / wav / ogg：会新建一首曲子并把音频设为其背景音乐（可选，纯合成曲可直接做谱）。
  • 或在编辑器顶部输入曲名、BPM、偏移直接开始空谱面编辑；点自定义曲卡片的 “编辑谱面” 可修改。（内置曲谱面为固定内容，不可编辑）

2. 认识参数

  • BPM：每分钟节拍数，决定网格与音符吸附的疏密。
  • 偏移（秒）：整份谱面相对音乐整体后移的时间，用于对齐前奏。
  • 吸附：音符自动贴齐 1/4 拍、1/8 拍或 1/16 拍（可关）。移动鼠标时画面上会出现一条金色虚线，表示音符当前会吸附到的拍点位置，方便卡准。

3. 添加音符

  • 普通音符：在上 / 下两条轨道点击空白处，音符落在该时刻、该轨道。
  • 长按音符：按住 Shift 再点击轨道，会生成一个长按音符（圆点下方带竖条），需要按住按键直到竖条走完。
  • 双押音符：同一时刻在上下两条轨道各放一个音符，游戏里两个音符都会套上金色光圈，表示需要两键同按。

4. 调整音符

  • 移动：按住音符圆点拖动，可改轨道和时间（自动吸附）。
  • 时长：长按音符下方有尾部小柄，按住小柄上下拖动可拉长 / 缩短按住时长。
  • 删除：右键点击音符。
  • 清空：点编辑器顶部的“清空”。

5. 试听

  • 按 空格 或点“播放 / 暂停”从头试听，黄色竖线是播放光标；配有鼓点节拍器，方便对拍。
  • 导入的音频会同步播放；没导入音频也能听节拍和音符声。

6. 保存与游玩

  • 点 “保存到曲库”：谱面存入曲库（浏览器本地保存），自动计算难度等级。
  • 点 “导出 JSON”：下载谱面文件留档或分享。
  • 回曲库点 “游玩”，用 A S D F / J K L ; 键敲击，长按按住不放，双押两键同按。

小提示：音符越接近拍点判定越准（正中靶心 = PERFECT）；难度由音符密度自动评定；每首歌会记录你的历史最佳成绩。
